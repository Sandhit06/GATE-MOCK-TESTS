## Local workflow

Python 3.10+; no API keys or model calls are required by the publishing engine. Questions must first be authored and independently verified in `data/questions.jsonl`.

```text
python scripts/build.py --paper 1 --resume
python scripts/build.py --start 2 --end 10 --resume
python scripts/validate.py --paper 1
python scripts/validate.py --final
python scripts/report.py
python -m unittest discover -s tests -v
```

Optional printable HTML: `python scripts/export.py --paper 1` (requires `markdown-it-py==3.0.0`). Open the exported HTML in a browser and use Print / Save as PDF. Markdown remains primary; no web server is required.

Build and validation fail on incomplete or unverified content. Resume preserves identical publications and refuses to overwrite differing files. A failed final audit remains failed until all 100 complete papers and 6,500 accepted records satisfy its checks.
